# Навчальні профілі для адміністратора

- `/profile` і `/admin/users/[id]/profile` використовують спільний `LearningProfile`: однаковий розрахунок прогресу, найкращих балів, активності, історії та сертифікатів.
- Новий маршрут перевіряє роль ADMIN перед запитом даних обраного користувача. Адміністратор може відкривати його сертифікати; для інших ролей збережено доступ лише до власних сертифікатів.
- У списку користувачів і картці працівника є перехід «Навчальний профіль». Звідти можна перейти до редактора даних, а з власного профілю адміністратора — одразу до своїх даних.
- Чужий навчальний профіль відкривається для перегляду: без керування фото та без дій від імені працівника. Клієнтські компоненти отримують лише потрібні для відображення поля.
- Збереження власного імені більше не блокується незмінними полями ролі та статусу. Форма не надсилає ці поля, коли їх редагування заборонене; API зберігає заборону змінювати власні права, блокувати чи видаляти себе.
- Для старих акаунтів часткове редагування імені зберігає решту наявних частин ПІБ. Порожнє ім’я не приймається.

Перевірено 169 автоматичних тестів і 20 браузерних сценаріїв на 320/390/768/1440 px, включно зі збереженням імені через синтетичний API та захистом від подвійного надсилання. Дані реальних користувачів під час цих перевірок не змінювалися.

Браузерні артефакти: `reports/admin-profiles-2026-10-24/`.
